- **About**: background and how I work
- **Contact**: [get in touch](https://arhamj951.github.io/#contact)

## Tech

Plain static HTML, CSS, and JavaScript with no build step, hosted on GitHub Pages.

```
index.html               # the page
styles.css               # styles
script.js                # mobile menu behaviour
assets/                  # SVG artwork
mockups/                 # design explorations
DESIGN-PHILOSOPHY.md     # the visual direction behind the site
DEPLOY.md                # GitHub Pages deployment notes
```

## Running locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```
